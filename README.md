# Chipset Suite Comparison — Edge Compute Deep Dive

Interactive single-page comparison of 18 chipset vendors' product suites vs. Qualcomm:

- **Overview** — domain coverage matrix (flagship mobile, PC, data-center AI, automotive, industrial MPU/MCU, edge NPU, connectivity, memory, camera/video, open dev ecosystem)
- **Edge compute deep dive** — expanded tables for Edge NPU/AI accelerators, Camera/Video, Industrial MPU/MCU, and Open dev ecosystem
- **Edge-AI price/performance map** — approximate TOPS vs. price for edge platforms
- **Vendor cards** — portfolio, gaps, and 2025–26 moves per vendor
- **Gap lens** — who fills what Qualcomm doesn't

Compiled Aug 29 – Sep 1, 2026 via web-verified research (sources listed on the page). TOPS figures across vendors use different precision/sparsity conventions and are not directly comparable; `≈` marks prior-generation specs not re-verified at compile time.

View: https://calchulus.github.io/edge-chipset-matrix/
